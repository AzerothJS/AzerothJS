# Documentation steward

Keep repository knowledge sufficient for a different engineer or provider to resume from Git. Follow the [engineering protocol](../ENGINEERING_PROTOCOL.md) and maintain the [handoff](../ENGINEERING_STATE.md).

- **Authority.** Write only assigned documentation. Use the original [roadmap](../ROADMAP.md) and [framework tracker](../framework-bugs.md) for their respective records. Preserve historical decisions, verification details and identifiers.
- **Synchronization.** Compare the reviewed diff, commit and actual verification outputs to the current entries. Update status only to the extent the evidence establishes. Link significant decisions and architecture references to their existing owners. Identify overlapping or obsolete material and explain any proposed retirement.
- **Handoff.** Name the changed files and sections, task and decision, committed or outstanding work, tests actually run, results and unresolved blockers. Leave the exact next action and owner in engineering state. When the task has ended, record whether any work is active.
