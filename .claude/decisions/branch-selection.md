# Preserving the selected conditional branch

## A-121 and A-211

At `3d0846a` the dispatch editor lost its draft, selection, focus and original shortcut listener on every fresh record. The compiler emits the same zero-argument child for plain Show markup as a manual rebuilding thunk. Switch's effect reads each condition directly. In both cases an ordinary source update runs the effect's teardown before it can decide whether the same branch still wins. Separately, a throwing root disposer bypasses range clearing. The next showing appends a second ticket.

## Decision

Route compiled Show tags through an internal helper, including children supplied through attributes and spreads. The helper checks the callee's identity because an expression-local binding can shadow the framework Show. It forwards the original argument list to user functions. Preserve the public one-argument Show signature, its manual thunk refresh, value-callback strict setup, and direct Suspense driver. Compiled plain Show selects by truthiness. An ordinary or explicit-arrow child factory runs once on entry. A genuine flip replaces the branch. Reactive markup and a sole expression hole continue updating their own contents. A component setup snapshot or an explicit arrow that chooses a subtree needs a reactive markup read or an intentional conditional or keyed boundary to refresh.

The new internal helper requires the matching runtime, so move the emitted and runtime contract together to v6. Register the current unreleased 2.1.1 train as the earliest allowed version. Rebuild precompiled components with a matched set. Explicit imports of the framework Show work in markup and one-argument manual calls retain their semantics. An unrelated component imported under the same name gets its original call. This changes no source grammar, serializer, package version or public runtime export.

Use one ordered, short-circuiting selection per Switch mount. Swapping depends on the winner's position and current render method. The fallback is a distinct selection. A replaced public render method starts a new showing even at the same position. A normalized value Match exposes its sampled condition to the winning branch. Selection and live reads share the sample. Publish observed truthy values to that showing's retained binding, including when no child has pulled it. A losing binding cannot consume another case's value. Keep per-mount state off reusable case descriptors. Preserve manual `Match.render()` and structural cases with custom predicates and factories. Use the same choice logic and constant selected sample in SSR. Buffered and streamed hydration adopt before subsequent real swaps.

A failed predicate is distinct from a false condition and from a successful selection. Deliver it through the branch effect once, remove an outdated branch without mounting a fallback, and retry on the next relevant input, even if the same position wins again. Plain Show and Switch can recover from an initially handled predicate failure. Keep A-262's existing initial construction rollback for a value-callback Show. Preserve the initiating exception during branch disposal and remove its range even if cleanup throws. Teardown must remain neutral to tracking and permit reopening.

An arity-one wrapper around all authored children cannot preserve both initial-failure contracts. An alias for the internal Show alone misses an explicit public Show import. A memo per case would evaluate hidden guards. Comparing render functions loses case identity when two cases share a factory. Tracking a mutable winner on a descriptor couples independent mounts. Preserving genuine swaps also preserves the lifecycle reason for putting element-specific listeners on a markup binding, a ref or a component mounted with the node.

## Acceptance

Compare client render, initial server output, hydration, held input, real swaps and cleanup failures. Exercise ordered guards, custom and reused cases, retained callbacks, exact error delivery, failed selection recovery, batched reads and one sample per selected value. Verify nested keyed rows and manual compatibility. The packed three-engine dispatch app and the registered Playwright MCP agent must reproduce the old behavior and validate the fix. Run targeted fault variants, the full repository gate and package smoke. The selection work uses the existing reactive graph, introduces no rendering sink and uses a microtask to report an independent error if throwing cleanup prevented normal delivery. Record sibling teardown findings under their own owners.

## Verified behavior

- The nine baseline suites passed 285 tests. The packed baseline reproduced draft loss in selected Show and Match editors and in both fallbacks. All four lost focus, the caret range and the original shortcut listener on a same-selection refresh. On both archive controls the original error surfaced, one ticket remained after close and two appeared after reopening.
- The original arity-one proposal would have changed recovery from an initial failure under `catchError`. Design refutation distinguished the strict value-callback Show contract from the retryable compiled plain Show and Switch. Implementation review also exercised failure during child construction, fallback lookup and adoption, a condition-owned cleanup that throws while resampling, independently failing teardown and predicate, user replacement of a winning render method, and disposal that detaches a descendant or a marker. Failed builds release partial nodes and retry on a later qualifying sample. Once a branch successfully mounts, an equal selection preserves it, including a branch that intentionally produced no nodes.
- A packed v5 module failed the v6 handshake with the instruction to rebuild. A v6 Show module on the v5 runtime failed ESM linking on the missing `renderShow` import. The matched v6 module loaded. The compiler and source projection distinguish ordinary, explicitly imported and shadowed Show names. Module and lexical bindings spelled with Unicode escapes also keep their original meaning. A direct check of the built language service returned the new branch-listener guidance for `mount`.
- Chromium 151, Firefox 153 and WebKit 26.5 each exercised buffered SSR, assembled streaming output and client-only rendering. On the corrected build all 36 editor scenarios kept the original input, `abcdef`, focus, caret range 1–4 and the working shortcut listener through refresh.
