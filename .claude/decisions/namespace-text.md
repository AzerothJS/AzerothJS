# Text in HTML, SVG and MathML templates

## A-234 and A-237

At `9e15126` the compiler's clone serializer copies HTML script and style source directly. The server applies its raw-text transform. Both serializers escape plain text in legacy HTML raw-text elements, although a browser preserves those entity spellings. The compiler also chooses the HTML content model for a foreign element with the same local name. A clean SVG stylesheet inside CDATA retains the delimiters when constructed as DOM nodes. An SVG title rejects nested elements during compilation.

## Decision

Resolve host namespaces while parsing the template. Keep that information in the render plan and across lexical children and expression re-entry. Use the existing tag inference for a detached root with no parent. The runtime semantics module owns the HTML content rules, foreign text rules, and SVG and MathML integration points used by projection, cloning, SSR and DOM construction. Use typed, inert data and ordinary CSS for verification.

Serialize HTML script and style with the existing server transform. Preserve decoded static legacy text where the HTML tokenizer can represent it and diagnose an unrepresentable value. Foreign script and style contain literal text. Unwrap CDATA in that context and escape the resulting text when writing HTML. An SVG title or description can contain HTML children. An explicitly placed host checks its local name and namespace during adoption. Buffered and streamed rendering share the same SSR serialization. [HTML tree construction](https://html.spec.whatwg.org/multipage/parsing.html#tree-construction)

Use an internal namespace-aware host constructor and extend the clone factory with an optional namespace for detached roots. Intern templates using both bytes and parsing context. Keep the public eager constructor and existing component, scope, cancellation and ownership semantics. Inferring a future parent for an already constructed public node would require delaying its construction or replacing it after refs and listeners have run. An unrelated component's placement is still tracked under M15-66. Using HTML script escaping in SVG would change the decoded text. Rejecting all foreign style content would also reject ordinary styles that browsers support.

The internal helper adds a compiled dependency. Move the compiler and runtime together to contract 7 on the existing unreleased 2.1.1 train. Rebuild the application, its precompiled components, and both SSR and client assets together. Keep ordinary HTML emission on the existing constructor where its inferred namespace matches. No new dependency or asynchronous state is needed.

Placement across a MathML annotation uses its absent or literal encoding. A runtime encoding or a spread beside markup children receives a located diagnostic. Applying an attribute after the clone was parsed cannot change the namespaces of its children. For HTML script and style, a direct DOM property contains the caller's string and serialization uses a spelling that preserves the JSON or CSS value. Only an own `innerHTML` property selects trusted markup.

The renderer creates a child before its eventual parent is known. For legacy raw-text elements, ordinary comparisons and ampersands are portable when followed by HTML whitespace or the end of the text. Refuse other continuations, carriage returns and null characters. Check a complete plain-text run, including values from getters and arrays. For an explicitly constructed tree that already contains branded markup, preserve ordinary-text escaping around that markup.

## Acceptance
