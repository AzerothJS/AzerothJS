# Reactive bindings inside render callbacks

Unit 9 covers A-213, A-214 and A-287 on `b945b60`. A host element returned directly by an arrow can be lowered to a clone sub-plan. The analyzer previously recorded only the enclosing arrow expression. Lowering supplied empty dependencies for inner holes without a scope, and code generation rewrote the detached body against component declarations. A separate prefix test treated a joined or indexed collection as a literal value.

## Design

The analyzer and lowerer must agree on which render callbacks have a host sub-plan. For these callbacks, record dependency and purity information for each detached binding under its lexical parameters, including nested host callbacks. The same lexical environment governs the binding rewrite. An ordinary row parameter shadows a namesake component source and an inherited getter. A control-flow binding declared with `let=` continues to read the runtime getter. A missing entry in analyzed component output is a compiler invariant violation. Embedded markup lowered without component analysis continues to use the expression's shape. The detached plan accepts simple identifier parameters and a direct host body. Complex headers stay with the existing whole-arrow emitter, which walks parameters and their initializers together. Destructured component props that need a stable receiver or a lexical default capture it outside the row. A missing prop evaluates its default lazily on each read. Sibling-dependent destructured defaults remain tracked under A-171.

The expression classifier inspects the complete TypeScript expression after accounting for embedded markup. A member, index, call or conditional following a collection is a computation. A literal passed to a component prop retains its value semantics, including collections of resources and function-valued props. Preserve the existing computed interpretation of an explicitly parenthesized collection. The editor projection and both runtime emitters must use the same classification. Limit parsing to candidate spellings on this hot path.

The runtime, syntax and package contract version stay compatible. Subscriptions belong to the existing binding owner in client render and hydration. A reactive text hole can introduce SSR markers where older output serialized bare text. A cached older document uses the existing hydration recovery path. This changes the lifetime of an arrow child's own text and attributes, including draft inputs in tracked wrappers. Setup reads in an error boundary remain a separate concern (A-259).

## Acceptance

Execute compiled host, spread or ref, nested and raw cases with changing inputs in render, explicit client output and SSR/hydration. Check the handler argument and draft identity in addition to the rendered text. Check a component alias, state and derived shadow, an unshadowed capture, and a row parameter named `props`. Compare computed collections and an invoked arrow with live twins, genuine collection values, and the editor projection. Check the baseline and corrected packed application in a browser, run the compiler suite and repository gates, and submit the actual diff for independent review.

Wrapping every binding in a getter would change the public meaning of value props and genuine callbacks. Rebuilding a wrapper to reread the arrow would discard its subtree. Neither supplies lexical binding information to the detached rewrite. The existing scope walker, expression parser, placement ownership and render modes provide these mechanisms.

## Review conditions

Independent probes identified two additional lexical cases. A row named `props` can capture the generated receiver of a different destructured component alias. A default parameter can refer to an outer alias or to a later parameter in JavaScript's temporal dead zone. Validate both clone and whole-arrow output. Also preserve the existing meaning of a comment-led hole beside `let=` and check that computed collection text receives its outer SSR markers while its nested fallback keeps its own markers.
