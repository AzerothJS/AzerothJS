# Architecture and engineering knowledge

Use this index to find the implementation, its tests and the design record for the task. The bootstrap inventory was taken on `a9eb35c`. Recheck the package manifest, source and relevant tests at the revision under review before relying on a historical claim.

| Question | Where to look |
| --- | --- |

| Where is the approved design? | Start with the dossier named in the roadmap entry. Topic files live directly in `.claude/`. Read the decision, review outcome and later amendments together. Some files are proposals awaiting review. |

The original checkout contains 70 pre-bootstrap Markdown files under `.claude/` outside its worktrees. Git tracked none at `a9eb35c`. A checkout missing either canonical file needs the originals from the project owner before work that depends on their contents can resume. Preserve their paths and history. Check availability with `git ls-files -- .claude/ROADMAP.md .claude/framework-bugs.md` and check the files on disk separately.

Git runs its own [pre-commit](../.husky/pre-commit) and [pre-push](../.husky/pre-push) hooks. Keep private local settings and nested worktrees out of shared configuration.
