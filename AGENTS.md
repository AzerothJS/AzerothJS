# Working on AzerothJS in Codex

Begin each task in [.claude/ENGINEERING_PROTOCOL.md](.claude/ENGINEERING_PROTOCOL.md) and read the current [.claude/ENGINEERING_STATE.md](.claude/ENGINEERING_STATE.md). Open the canonical `.claude/ROADMAP.md` and `.claude/framework-bugs.md` as directed there. Use the [.claude/ARCHITECTURE_INDEX.md](.claude/ARCHITECTURE_INDEX.md) to locate the relevant contracts, source and tests.

The principal engineer applies that lifecycle. For each delegated assignment, read its [.claude/agent-specs](.claude/agent-specs/) file. The corresponding project agents are in `.codex/agents/`. Work from the repository root in a trusted project session to load project configuration. Follow the handoff's next action when resuming.
